You are checking ONE invariant across the whole client codebase. This is not a
file review. Do not report general code quality. Report only violations of the
stated invariant, plus anything that makes the invariant unverifiable.

## The invariant

Every key this application writes to `localStorage` or `sessionStorage` is
removed when a user logs out.

Rationale: two people share a browser. If a key written for user A survives
user B's login, user B sees or acts on user A's state.

## Method

1. Find every write to `localStorage` and `sessionStorage` in `client/` and
   `src/`. Include indirect writes through any wrapper or hook, and follow the
   wrapper to the real key. Search for `setItem`, `removeItem`, and any helper
   that takes a key name.
2. Collect the complete set of key names, including keys built from a template or
   a prefix plus a variable.
3. Find the logout path. Determine exactly which keys it removes and by what
   rule (exact name, prefix match, full clear).
4. For each key from step 2, decide whether step 3 removes it. Show the rule you
   applied.
5. Report every key that survives logout.
