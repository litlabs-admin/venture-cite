You are checking ONE invariant across the whole repository. This is not a file
review. Report only violations of the stated invariant, plus anything that makes
the invariant unverifiable.

## The invariant

Every page component rendered by a route is reachable from the running application through navigation, a link, a button, or a documented redirect.

Rationale: Unreachable pages are either dead code to delete or working features nobody can find.

## Method

1. Enumerate every route defined under src/routes/ and every page component under client/src/pages/.
2. Find the navigation definitions, including the sidebar, any tab strips, dashboard cards, and any programmatic navigate() calls.
3. For each route, find at least one inbound path a user could follow. A redirect shim counts if something reaches the redirect.
4. Report every route with no inbound path. State whether it looks abandoned or intentionally hidden.
