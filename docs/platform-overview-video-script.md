# VentureCite Platform Walkthrough Script

**Runtime:** about 15 minutes in full. See the trim plan at the end to cut it down.
**Format:** one continuous recording, played straight through the table below.
**Voice:** plain and confident, like a person showing a coworker around. No hype words, no dashes, no jargon left unexplained.

Checked directly against the live app on August 4, 2026 (commit `d7d7110`). If you're comparing this to older internal notes, see "What changed since the last script" at the very end. Swap in your real demo brand name wherever the script says "your brand."

---

## Before you record

- Log in with a demo brand that already has real data: a finished citation scan, some fact sheet facts, at least one competitor, one generated article, and a populated Report page.
- Set your browser zoom to about 110 to 125 percent so text reads clearly on screen.
- Close other tabs, hide your bookmarks bar, turn off notifications.
- Do one silent run through the whole click path first, so you're not hunting for tabs on camera.
- Decide if you're including the optional Getting Started row. Include it for people who've never used the app. Skip it for a refresher aimed at existing users.

## Trim plan, getting from 15 minutes down to 9 or 10

Cut in this order until you hit your target length.

1. Skip Getting Started entirely. Mention setup in one sentence in the intro instead. Saves about 1:15.
2. In Act, fully demo only Create and one other tab. Name the remaining four in a single sentence each. Saves about 1:30.
3. In Monitor, collapse Trends and Mentions into one sentence each instead of a full row. Saves about 0:45.
4. In Diagnose, Signals, skip Chunk Engineer and Schema Lab, mention Signal Scorecard only. Saves about 0:30.
5. Drop any live Run Check or live Generate moment, just show the finished result instead. Saves 0:45 to 1:00.

## Notes for whoever records this

- Leave about a one second pause between rows, it helps auto chapter tools split cleanly if you use one.
- When you point at a number, say the actual number out loud. "You're cited in four of ten ChatGPT answers" lands better than "as you can see here."
- Don't overstate anything. Keywords numbers are estimates, say estimate. Report numbers are measured, say measured.
- If something on screen is loading (a scan, a generated article), keep talking about why it matters while it loads. Don't sit in silence.
- Keep the cursor calm. Move it with a purpose, don't circle it around while you talk.
- No hype words anywhere in the script: nothing gets "unlocked," nothing is "revolutionary," nothing "empowers" anyone. Just say what it does.

## What changed since the last script (June 18, 2026 notes)

If you're working from older internal notes, here's what's different in the app today:

- The home page is called **Dashboard**, not Command Center. That name was retired.
- **Monitor lost its Overview tab.** Its old charts either moved to the Dashboard or were removed because they weren't backed by real data. Monitor now has four tabs: Citations, Competitors, Trends, Mentions.
- **Citations lost its Schedule tab.** Only Prompts, Latest Results, and History remain.
- **Trends now tracks one thing only**, unresolved hallucinations over time. It is not a general visibility trend chart.
- **The Visibility Checklist has no "Quick Wins" section.** That was never a real feature. It covers eight AI engines, not six.
- **The Dashboard's six main numbers are Visibility, Mentions, Rank, Citations, Hallucinations, and Listicles.** Two numbers that used to be there, AI Traffic and Conversations, were removed because the app had no real way to measure them.
- **Only four AI platforms show live data** on the Dashboard's platform row: ChatGPT, Claude, Perplexity, and Gemini.
- **Signal Scorecard's pipeline view is now a section inside that same tab**, not a separate tab. There is no separate Freshness tab either, it's folded into the scorecard.
- **Report has no revenue or ROI numbers, on purpose.** It only shows measured citation data.
- **No team or multi user features exist in the app today.**
